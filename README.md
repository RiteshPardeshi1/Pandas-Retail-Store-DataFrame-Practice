# Pandas DataFrame Practice: Global Retail Store

Pandas DataFrame practice using a global retail store dataset.

## What's Inside

- DataFrame analysis on retail store data

## Tech Stack

Python, Pandas, Jupyter Notebook

## How to Run

1. Clone the repository
2. Install the libraries: `pip install jupyter pandas`
3. Open the notebook with `jupyter notebook` and run the cells in order
